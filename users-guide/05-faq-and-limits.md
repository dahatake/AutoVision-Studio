# 05. よくある質問と現在の制限

## 現在の制限（開発版）

| 機能 | 状態 |
|---|---|
| Project 作成・設定・一覧 | 利用可 |
| 画像の取り込み（コピー／参照、5 種類の形式） | 利用可 |
| 画像分類のラベル付け、物体検出の矩形描画、Dataset の確定 | 利用可（署名前ビルドで確認） |
| 学習の実行・履歴・進捗 | **未実装**（Dataset 確定後の待ち行列登録まで） |
| 結果レポート、モデル版の比較 | **未実装** |
| カメラ推論・推論設定 | **未実装**（カメラにはアクセスしません） |
| 補助ジョブ（モデルによるラベル候補） | **未実装** |
| Windows インストーラー、署名済み配布物 | **未提供** |
| macOS、Windows 10、ARM | Version 1 の対象外 |

最新の進捗は [README の「現在の利用可否」](../README.md#現在の利用可否) と [実装計画](../docs/implementation-plan.md) を確認してください。

## よくある質問

**Q. 起動してもウィンドウが何も表示されない／操作できない**
A. 「Project 管理に接続できません。作成・作業は利用できません。」と表示される場合は、アプリの内部機能に接続できていません。`npm run build` をやり直してから起動し直してください。

**Q. 「データを選択して検査」でエラーになる、検査が進まない**
A. 画像の検査は Python のワーカーが行います。`ml/` で `uv sync --locked --system-certs` を実行して環境を整えているか確認してください（[開発・カスタマイズガイド](../docs/developer-guide.md)）。

**Q. ［取り込む］が押せない**
A. **［データの利用権利］** のチェックが必要です。また、検査でエラーが残っていないかを「問題一覧」で確認してください。

**Q. 取り込んだのに、画像が「未着手」「未確認」になっている**
A. 仕様です。ラベル付きで取り込んだ画像も、人が確認するまで正解（Ground Truth）にはなりません。**［確認済みにする］** を押してください。

**Q. ［確認済みにする］が押せない**
A. 画像分類では、クラスが 1 つ割り当てられていて、除外されていない必要があります。物体検出では、矩形が 1 つ以上あるか、「対象物なし」を明示している必要があります。

**Q. ［Dataset を確定する］が押せない／確定できない**
A. 確認ダイアログに「Error が残っているため確定できません。」と出ている場合は、エラーの内訳（Schema 外のクラス、不正な矩形、保存データの不整合など）を解消してください。

**Q. 「参照」で取り込んだ画像が開けなくなった**
A. 元ファイルが移動・削除された可能性があります。［教師データ］の「参照元（Reference）の確認」で **［参照元を確認］** → **［参照元を選び直す］** を使います。元と同じ内容のファイルだけが受け付けられます。

**Q. 取り込みの結果が「不明」と表示された**
A. 取り込みをやり直さず、**［状態を再確認］** を押してください。やり直すと二重に取り込まれるおそれがあります。

**Q. 学習を始めたいのにボタンがない**
A. 学習はまだ実装されていません。［学習］タブには「未実装です」と表示されます。

**Q. 画像やラベルは外部に送られますか？**
A. 送られません。画像、ラベル、モデル、推論結果は端末内だけで扱う設計です。カメラも、推論開始時の許可を求めるまでアクセスしません（推論は未実装です）。

**Q. 取り込む画像の権利は？**
A. 画像・ラベル・アノテーションを利用・学習する権利の確認は、利用者の責任です（取り込み時にチェックが必要です）。同梱サンプルにも利用条件があります。

**Q. スクリーンショットが実際の画面と違う**
A. 開発中のため画面は変わります。[撮影スクリプト](../scripts/docs/capture-screenshots.mjs) で撮り直せます（[README](README.md#画面キャプチャについて)）。
