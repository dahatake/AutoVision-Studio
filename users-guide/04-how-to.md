# 04. 操作ガイド（目的別）

画面の場所は [03. 画面ガイド](03-screen-guide.md) を参照してください。最短の流れは [02. クイックスタート](02-quickstart.md) にあります。

## 全体の流れ

```text
Project を作る → 画像を取り込む → ラベルを確認・付ける → 確認済みにする → Dataset を確定する
                                                                      ↓
                                         （学習 → 結果 → カメラ推論：Version 1 の目標・未実装）
```

## Project を作る

1. ヘッダー **［Project 一覧］** → **［Project を作成］**。
2. **［親フォルダーを選択］** で保存先を選び、**名前**を入力し、**タスク種別**（画像分類／物体検出）を選びます。
3. **［作成］**。

ポイント:

- タスク種別は最初の学習を作るまで、[設定 → Project] で変更できます。迷ったら先に画像で 1 つ試してください。
- 保存先は十分な空き容量のあるドライブを選びます。
- Project の保存先は、あとで [設定 → Project] の **［保存場所を変更］** で移動できます。

## データを用意する

どの形式でも、画像は JPEG、PNG、WebP、BMP、TIFF のいずれかです（アニメーション画像は不可）。壊れた画像は黙って除外されず、検査結果の「問題一覧」に報告されます。

| タスク | データ形式 | フォルダーの例・必要なもの |
|---|---|---|
| 画像分類 | **クラス別フォルダー** | `images/healthy/…`、`images/bean_rust/…`（直下のフォルダー名がクラス名） |
| 画像分類 | **CSV ラベル** | 画像フォルダーと、`path,label` の見出し行がある UTF-8 の CSV（`path` はフォルダーからの相対パス） |
| 画像分類／物体検出 | **ラベルなし・フォルダー** | 画像フォルダーだけ（ラベルは取り込み後に付ける） |
| 画像分類／物体検出 | **ラベルなし・画像ファイル** | 画像ファイルを複数選択 |
| 物体検出 | **COCO アノテーション** | 画像フォルダーと COCO 形式の JSON |

**コピーと参照の違い**（取り込み時に必ず選びます）

| 方法 | 動作 | 向いている場合 | 注意 |
|---|---|---|---|
| **コピー（推奨）** | 画像を Project の保存先へ複製 | 基本的にはこちら | 画像と同じ量の空き容量が必要 |
| **参照** | 元の場所の画像をそのまま使う | 容量を節約したい | 元ファイルを移動・削除・変更しないこと。アプリは元ファイルを変更しません |

## 画像を取り込む

1. **［取り込む］** タブでデータ形式と取り込み方法を選びます。
2. **［データを選択して検査］** でフォルダー（CSV／COCO では続けて注釈ファイル）を選びます。選ばずに閉じると「選択をキャンセルしました。」と表示され、検査は始まりません。
3. 検査結果を確認します。エラーが 1 件でもあれば、「問題一覧」で内容を確認してください。
4. **［データの利用権利］** のチェックを入れ、**［取り込む］**。
5. 「取り込み完了／画像は未確認です」と表示されます。ラベル付きで取り込んだ画像も、まだ**未確認**です。

> 結果が確認できず「取り込み結果が不明です。状態を再確認してください。」と出たときは、取り込みをやり直さず **［状態を再確認］** を押してください。

## 画像分類のラベル付け

1. **［教師データ］** タブを開き、画像を選びます。
2. **［クラス］** で 1 つ選びます（1 画像に 1 クラス）。外すときは **［クラスを解除］**。
3. 学習に使わない画像は **［除外理由］** を選んで **［除外にする］**。
4. **［確認済みにする］**。押せるのは、クラスが割り当てられ、除外されていない画像だけです。
5. 「表示分の未確認」が 0 件になるまで続けます。

便利な操作:

- **状態で絞り込み** で「未着手」だけを表示すると、残りを数えながら進められます。
- 画像一覧は矢印キー（←→↑↓）でも移動できます。
- **［元に戻す］／［やり直す］** で編集を戻せます。

## 物体検出の矩形を付ける

1. **［教師データ］** タブで画像を選ぶと検出キャンバスが開きます。
2. **新規領域のクラス** を選び、物体の上をドラッグして矩形を描きます。
3. 矩形ごとのクラスは **領域一覧** で変更できます。複製は Ctrl+D、全選択は Ctrl+A、削除は Delete、選択解除は Esc です。
4. **［拡大］［縮小］［全体表示］** で表示を調整します。
5. 物体が写っていない画像は「対象物なし」を明示して確認します（未着手とは区別されます）。
6. **［確認済みにする］** を押します。領域が 1 つもないときは、対象物なしの確認が必要です。

## ラベル定義と作業指示を整える

- **［ラベル定義］**（設定、または作業画面の **［ラベル定義］** ボタン）でクラス名と **作業指示** を編集します。
- 作業指示は、複数人や後日の判断を揃えるための基準です。「どこまで含めるか」「小さすぎる物体は付けるか」などを書いておくと、教師データ画面に常時表示されます。
- 空白だけの名前や、同じ名前の重複は保存できません。

## Dataset を確定する

1. ［教師データ］タブで未確認を 0 件にします。
2. **［Dataset を確定する］** を押します。
3. 確認ダイアログで件数（全件・確認済み・除外・エラー）と由来の内訳を確認し、確定します。エラーが残っていると確定できません。

確定した Dataset Revision は不変で、後から書き換えられません。

## 参照で取り込んだ画像のリンクを確認する

「参照」で取り込んだ画像の元ファイルを移動・削除すると使えなくなります。

1. **［教師データ］** タブの「参照元（Reference）の確認」で **［参照元を確認］**。
2. 確認できないものがあれば、一覧に理由が出ます。行の **［参照元を選び直す］** で元と同じ内容のファイルを選びます。内容（サイズと SHA-256）が一致しないファイルは受け付けません。

## Project の保存先を移動する・削除する

- 移動: 設定の **Project** → **［移動先の親フォルダーを選択］** → **［保存場所を変更］**。移動の前に、Project 情報を保存するか変更を破棄してください。
- 削除: Project 一覧の **［削除対象を確認］**。何が削除されるかを確認してから実行します。「参照」で取り込んだ元ファイルは削除されません。

## 端末の状態を確認する

設定の **端末・容量** で、OS・CPU・メモリ・ディスクを確認できます。**［診断要約を保存］** で結果を保存できます。
