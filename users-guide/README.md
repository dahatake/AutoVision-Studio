# AutoVision Studio はじめてのユーザーガイド

AutoVision Studio を初めて使う方のためのガイドです。画面のどこで何ができるか、最初の 15 分で何を試せばよいかを説明します。

> **現在の状態（開発版）**
> Version 1（MVP）は開発中で、完成アプリケーションとインストーラーはまだありません。このガイドの画面は、ソースからビルドした開発用アプリ（画面右上に「開発中」と表示）を撮影したものです。
> 使えるのは **Project の作成 → 画像の取り込み → 教師データ作成（ラベル付け）→ Dataset の確定** までです。学習の実行、結果レポート、カメラ推論は未実装で、画面には「未実装です」と表示されます。
> 製品としての操作手順や受入結果は [ユーザーガイド（詳細）](../docs/users-guide.md) と [実装計画](../docs/implementation-plan.md) が正本です。

## このガイドで使う言葉

| 言葉 | 意味 |
|---|---|
| Project | 画像、ラベル、学習結果などをまとめる最上位の単位。作成時に「画像分類」か「物体検出」を選びます |
| 画像分類 | 1 枚の画像に 1 つのクラス（例：healthy）を付けるタスク |
| 物体検出 | 画像の中の物体を四角（矩形）で囲み、クラスを付けるタスク |
| クラス / ラベル定義 | 付けるラベルの種類（例：healthy、bean_rust） |
| 取り込み | 手元の画像を Project に登録すること。コピーか参照を選びます |
| 確認済み | 人が内容を確認して「正解（Ground Truth）」にした状態 |
| Dataset Revision | 確認済みのデータを固定した、後から変わらない版 |

詳しい定義は [用語集](../docs/users-guide.md#用語集) を参照してください。

## 画面キャプチャについて

- 画像は [scripts/docs/capture-screenshots.mjs](../scripts/docs/capture-screenshots.mjs) が自動で撮影します。画面が変わったら、ビルド後に `node scripts/docs/capture-screenshots.mjs` を実行すると `images/` を更新できます。
- 撮影に使うデータは、リポジトリ同梱の公開サンプル（豆の葉の分類 [Beans](../docs/sample-data/beans.md)、小麦の穂の検出 [GWHD](../docs/sample-data/gwhd-2021.md)）です。ライセンスと帰属は各サンプルの文書を参照してください。
- 撮影用の一時データは `C:\AutoVisionDemo\` 以下に作られ、終了時に削除されます。
