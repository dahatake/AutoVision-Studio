# 01. 準備と起動

## 1.1 できること・できないこと（開発版）

| できる | まだできない |
|---|---|
| Project の作成・一覧・設定 | 学習の実行・履歴・進捗 |
| 画像とラベルの取り込み（コピー／参照） | 結果レポート・モデル版の比較 |
| 画像分類のラベル付け、物体検出の矩形描画 | カメラでの推論 |
| ラベル定義と作業指示の編集 | 補助ジョブ（モデルによるラベル候補） |
| Dataset の確定（学習待ちの登録まで） | 一般向けインストーラーでの配布 |

画像・ラベル・結果はこの端末の中だけで扱い、Cloud へは送信しません。

## 1.2 動作環境

- Windows 11 24H2 以降、x64（Windows 10、ARM、macOS は Version 1 の対象外です）
- 十分な空き容量（コピーで取り込むと、画像と同じ量が Project の保存先に増えます）

## 1.3 起動する（開発版）

インストーラー版はまだないため、ソースからビルドして起動します。必要なツールのバージョンは [開発・カスタマイズガイド](../docs/developer-guide.md) の「ツール」を参照してください。

PowerShell でリポジトリのルートから実行します。

```powershell
npm ci
npm run build
.\node_modules\.bin\electron.cmd .
```

- 画像の取り込み検査には Python のワーカーを使います。`ml/` で `uv sync --locked --system-certs` を実行して環境を整えておいてください（詳細は開発・カスタマイズガイド）。
- 起動すると、ヘッダーに「開発中」バッジの付いたウィンドウが開きます。

## 1.4 画面の基本構成

アプリは 3 つの領域でできています。画面ごとの詳細は [03. 画面ガイド](03-screen-guide.md) にあります。

| 領域 | 場所 | 役割 |
|---|---|---|
| ヘッダー | 上端 | 「Project 一覧」と「設定」への移動、いま選択中の Project 名 |
| 本文 | 中央 | Project 一覧、Project の作業画面（タブ）、設定 |
| 共通状態バー | 下端 | ジョブの状況、診断結果、保存先ボリュームの空き容量 |

## 1.5 サンプルデータを用意する

初めて試すときは、リポジトリ同梱のサンプルが手軽です。

| やりたいこと | サンプル | 場所 | 取り込む形式 |
|---|---|---|---|
| 画像分類 | Beans（豆の葉 60 枚、3 クラス） | `resources/samples/beans/images/` | クラス別フォルダー |
| 物体検出 | GWHD（小麦の穂 20 枚、COCO 形式） | `resources/samples/gwhd-2021/images/` と `annotations.coco.json` | COCO アノテーション |

サンプルにも利用条件があります。取り込み時の権利確認の対象に含まれます（[Beans](../docs/sample-data/beans.md)、[GWHD](../docs/sample-data/gwhd-2021.md)）。

次は [02. クイックスタート](02-quickstart.md) に進んでください。
