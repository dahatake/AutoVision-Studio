# PKG-01 — 敵対的レビュー（model payload verifier）

対象: `scripts/models/verify.py`、`scripts/models/test_verify.py`、`resources/models/manifest.schema.json`（`3.0.1`、`approval.recordSha256`）、`resources/models/manifest.json`、`scripts/models/manifest-schema.test.mjs`、`docs/developer-guide.md` の検証の command、ADR-0004 §5.1.18、README L59。レビュー担当: rubber-duck agent（読み取りのみ。結果は記録者が転記）。

## 1 回目

| No | severity | location | problem | 対応 |
|---:|---|---|---|---|
| 1 | blocking | `verify.py` の CLI | 不正な JSON・形で traceback になり、`ready=true` で `models` が空でも通る | `run()` で入力の例外を「manifest could not be verified」と exit 1 に変え、空の `models` を拒否した。JSON Schema の検査は Python に依存（jsonschema）を加えず、既存の `manifest-schema.test.mjs`（ajv）と合わせて PKG-01 の照合とすると文書に明記した |
| 2 | blocking | path の検査 | 途中の symlink・junction、`\` の traversal、root を渡さない場合の `payloadPath` の traversal を通す | `\`・`:`・空・`.`・`..` の成分を拒否し、root から各成分を `lstat` して link・reparse point を拒否した。`payloadPath` にも同じ字句の検査を行う。junction の test を加えた（実行され skip されない） |
| 3 | blocking | license の検査 | 層を区別せず任意の `LicenseRef-*` を通す | code 層は許可の SPDX 識別子だけ、checkpoint 層は加えて `LicenseRef-AutoVisionStudio`（FR-LIC-016(3)）だけとし、式と URL は承認が無いため拒否した |
| 4 | blocking | 承認記録の検査 | 記録の bytes が固定されず、部分一致で通る | 行の値を太字と括弧の注記を除いて完全一致で比べ、artifact の SHA-256 を所定の行に限った（記録の digest は 2 回目の 1 で対応） |

## 2 回目

| No | severity | location | problem | 対応 |
|---:|---|---|---|---|
| 1 | blocking | 承認記録の bytes | schema の `$comment` の adoption の SHA-256 の照合を満たさない | schema を `3.0.1`（任意の `approval.recordSha256` を加えた ADDITION）とし、manifest の 4 件に記録の SHA-256 を置き、verifier と node の test で照合する |
| 2 | blocking | 承認記録の解析 | 最初の行だけを見るため、後の矛盾する行や別の digest を見落とす | 最終判定・承認者氏名・承認日の行はそれぞれ 1 行だけとし、artifact の行は 1 行だけで形を固定した。矛盾する行・複数の digest・固定の後の変更の test を加えた |
| 3 | non-blocking | path | Windows の予約名と末尾の点が通る | `ntpath.isreserved` と末尾の `.`・空白を拒否し、test を加えた |
| 4 | non-blocking | test | 許可の checkpoint license の肯定の test と、対応付けの出力の SHA-256・大きさの確認が無い | 加えた |
