> **いずれかの必須項目が空欄・`unknown`・不適合の場合、判定欄に「承認」と記入できません。**  
> **判定が空欄の場合も「未承認」として扱います（G-DEP-07/08 fail-closed）。**

| 項目 | 内容 |
|---|---|
| 最終判定 | [記入: **承認** / **却下** / **保留**] |
| 却下・保留の理由 | [記入: 該当する項目と理由、または "なし"] |
| 承認者氏名 | [記入] |
| 承認日 | [記入: YYYY-MM-DD] |
| 再審査期限 | [記入: YYYY-MM-DD または "設定なし"] |
| 法務確認の要否・状況 | [記入: 不要 / 完了（担当者・日付）/ 進行中] |

**判定の定義**

| 判定 | 意味 |
|---|---|
| **承認** | 全必須項目が `unknown` なしで完了し、全審査層が「適合」で、承認者が署名した |
| **却下** | いずれかの必須項目が不適合、または法務が不承認と判断した |
| **保留** | 審査継続中、または情報収集中 |

> 空欄・`unknown`・保留は「承認」と同等に扱いません。G-DEP-07（C6）/G-DEP-08（C7）の fail-closed 規則が適用されます。
> チェックリストの C7 専用項目は C6 では `N/A（C6）` と記録できます。それ以外の必須項目を `N/A` で省略できません。C6/C7 とも §10・§11 を完了し、C7 は §12 も完了した場合だけ最終承認できます。
