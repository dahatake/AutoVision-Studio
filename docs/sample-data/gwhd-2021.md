## 3. 個別取得の計画と停止境界

本節はDATA-04〜06への条件であり、**この文書leafでは画像・CSV・ZIPを取得しない**。

- 全体 `gwhd_2021.zip` は原記録の宣言サイズ **10215190132 bytes** [G1]。この承認では全体ZIP取得を禁止する。
- 公式container API [G5]は `entries` 998件、`total: 998`、`truncated: true` の応答である。998は全datasetの画像数・train母集団・完全なファイル一覧ではない。一覧から欠けていることだけで画像不存在とも判定しない。
- 同APIのtrain CSVは `gwhd_2021/competition_train.csv`、宣言サイズ **2841482 bytes**。公式 `links.content` は `https://zenodo.org/api/records/5092309/files/gwhd_2021.zip/container/gwhd_2021/competition_train.csv`。これはmetadata確認であり、CSV実体・実読出し量の検証ではない。

取得担当は次を順守する。

1. 元train CSVの `image_name` から20個の原IDを選定・固定する。実取得CSVは64桁小文字hexと`.png`からなるファイル名を含む。内部IDは末尾`.png`だけを除去し、元ファイル名を可逆に復元する。`gwhd_2021/images/` 内の対応だけを使い、preview一覧の先頭20件をtrainとみなさない。
2. 固定recordの公式個別URL（各ファイルの `links.content`）を使い、CSV所属と画像パスを照合する。未知ミラー、別dataset、HTTP Range、remote ZIP読取り、全体ZIPへのfallbackを使わない。
3. **固定20 IDのうち1枚で先にpilot（DATA-05）**を行う。原画像bytes・上流ファイル名・検出形式・対応CSV行・全box・座標意味・実読出し量を照合し、testと独立レビュー後に残りへ進む。pilotは完成20枚の一部であり、合格前に20枚を一括取得しない。
4. 原画像bytesをそのまま保持し、resize・再圧縮・crop・metadata書換をしない。全annotationを保持し、box間引き、不正boxの黙示補正、欠損時の別IDへの自動交換、枚数削減をしない。
5. **BeansとGWHDの2dataset合計**で、初回取得ファイル合計 **256 MiB = 268435456 bytes**、最終同梱資産合計 **96 MiB = 100663296 bytes**を守る。pilot・CSV・画像・証拠・通知等の取得を合算し、再取得分も取得量に含める。最終同梱は画像・annotation・manifest・通知を含む。未知sizeも実読出しbytesで上限停止し、展開・コピー用一時容量は別途検査する。
6. 取得不能、権利未確定、hash不一致、不正画像・座標、CSV欠損、選定20 ID内の重複、固定証拠と異なる未知の重複、件数不足、容量超過で停止する。取得は開発者の明示準備だけとし、通常build/test、install、初回起動、アプリ実行から自動取得しない。固定CSVのSHA-256が一致し、既知2組が選定20 ID外かつ記録済み行番号だけに現れる場合は、原行を変更・統合・採用せず`KNOWN_SOURCE_CONFLICT_OUTSIDE_SELECTION`として選定記録へ残す。

## 4. CSVからCOCOへの座標根拠

- 原記録[G1][G2]は列 `image_name`、`BoxesString`、`domain` を定義する。`BoxesString`は各boxの `xmin ymin xmax ymax` をセミコロンで連結し、boxがない場合は文字列 `no_box`。`domain`は撮影条件等のdomain情報であってカテゴリではなく、由来情報として保持する。カテゴリは `wheat_head` の1つだけ。
- 原記録の「image_nameは拡張子なし」という説明と異なり、取得したv1.0 CSVの3657行すべてに`.png`が含まれた。raw CSVは2841482 bytes、SHA-256 `1af1d8e386643afe8cd1b41d89ca2634d3212908bdbe58a9d7cd5b32e4048176`。この実体に合わせた厳密なファイル名検証を追加し、原CSVは書き換えない。全行のbox構文・範囲検査で不正0件だったが、これは画像との目視照合や通常importの合格ではない。
- `domain`の実体は整数ではなく、`Arvalis_1`や`ULiège-GxABT_1`を含む18種類のUnicode名称だった。内部IDや検出クラスへ変換せず、元の文字列を無改変でmanifestへ保持する契約へ修正し、単体テストと独立レビューで確認した。
- 2021年の作者Etienne David（`etienne_david`）による公式challengeのチュートリアル[G6]では、`WheatDataset.decodeString`がセミコロン→空白→整数の順で復号し、`no_box`を空box配列へ変換する。`albumentations==0.4.6`、`BboxParams(format='pascal_voc')`へ `xyxy` を渡す。
- 版固定の `bbox_utils.py` [G7]の `convert_bbox_from_albumentations` はCOCOの幅を `x_max - x_min`、高さを `y_max - y_min` とする。`normalize_bbox`と`check_bbox`は正規化座標の0〜1と厳密なmin＜maxを検査する。このコード経路を根拠に、原画像の各軸で **`0 <= xmin < xmax <= 1024`、`0 <= ymin < ymax <= 1024`** を条件とする。
- 変換は **`[xmin, ymin, xmax - xmin, ymax - ymin]`** とし、**+1を加えず**、原点の移動・座標の丸め・clampをしない。有限な4整数、正の幅・高さ、画像内範囲を全boxで検証する。原ID・CSV行・元box順序とCOCOの画像/annotation IDの対応を残し、全boxの件数と座標を逆変換で照合する。
- `no_box`は明示的な元annotationの0件であり、CSV行欠損・空欄・構文エラーを0件へ置換しない。取り込み後も人の「対象物なし」確認を省略しない。
- **参照は座標意味を確認するためのコード読取りだけ**である。チュートリアルの例外握りつぶし、`min_area=20`、box filter/clipping、画像変換、CUDA学習・pretrained modelを採用しない。関連ライブラリ、CLI、重みをinstall・取得・実行しない。

### 実CSVの競合重複（選定外に限定した警告根拠）

原CSVをヘッダー1行目として独立再確認した結果、以下の2 IDにそれぞれ異なる`BoxesString`と`domain`があった。完全一致の重複行ではない。

|---|---|---|
| `d88963636d49127bda0597ef73f1703e92d6f111caefc44902d5932b8cd3fa94.png` | 1988 / 2072 | BoxesString、domain |
| `1961bcf453d5b2206c428c1c14fe55d1f26f3c655db0a2b6a83094476e8edb5b.png` | 2001 / 2081 | BoxesString、domain |

どちらも名前順の先頭20候補には含まれない。2026-09-07にユーザーが、固定20件だけを独立審査する限定方針を承認した。原CSVのraw SHA-256が上記固定値と一致し、重複集合・行番号が上表と完全一致し、名前順の先頭20個の一意IDに含まれない場合だけ警告として続行できる。原行の削除、片方の採用、box統合、別画像への交換は行わない。選定内重複、未知の重複、行番号変化、CSV hash変化は停止する。この限定判断によりdataset全体が重複なし、正常、または学習適格になったとは扱わない。

親担当は保存した応答の**raw bytes**からhashを計算し、改行正規化後のhashと混同せず、保存copyの実在・一次資料との一致を確認する。本2文書のhashも内容確定後に親担当が記録する。ZIPのMD5、entry CRC、画像名を個別ファイルのSHA-256に転用しない。

本サンプルは通常Projectでの操作・学習フロー体験用の計画であり、公式benchmarkの再現や撮影session間の独立性、精度・所要時間を保証しない。元trainと利用者が作成するProject内splitは別物である。明示操作、保存場所・Copy/Reference・権利確認、人による画像全体の確認を維持し、取込annotationを自動的にGround Truthへ昇格させない。開いただけで学習・cameraを起動せず、人手確認後のRevision確定→自動Queue登録の通常要求は維持する。

素材の許諾はモデルの許諾ではない。`resources/models/manifest.json`を変更せず、未承認weight・偽の予測/学習結果を加えない。通知・由来はReferenceでもProject側へ保持してoffline閲覧可能にし、Project編集・削除で同梱原本や他Projectを変更しない。公開サンプルの審査済みpayloadと必要通知の同梱再配布だけを許し、サンプル由来を含むユーザーProject・編集データ・モデル・結果を外部送信しない。
