## 1. 本手順が必要な理由（自動 E2E で代替できない範囲）

[`tests/e2e/harness.ts`](../e2e/harness.ts) の `stubOpenDialog` は、main process の `dialog.showOpenDialog` を試験側から置き換える。これにより取り込み経路そのものは自動検証できるが、次は**置き換えによって検証対象から外れる**。

| 自動 E2E で検証済み | 本手順でしか検証できない |
|---|---|
| picker が返した path 以降の検査・取り込み・DB 記録 | **OS 標準ダイアログそのもの**が開くこと、その外観・既定の場所・フィルター表示 |
| `canceled: true` を返したときの UI 復帰 | 利用者が実際に **Esc / キャンセルボタン**で閉じたときの挙動 |
| 単一 path / 複数 path の受理 | Explorer 上での **Ctrl / Shift による複数選択**操作 |
| Reference 取り込み後のアプリ再起動、`av-image://` 経由の原本再読込、relink の受理／不一致拒否 | **OS 再起動**をまたいだ Reference アクセス |
| — | 署名前 package としての実行（`app.isPackaged === true` 経路） |

---

## 2. 事前準備

1. 署名前 package を作成する（`electron-builder`）。**開発ビルドで代用しない。**
2. Reference 用の元データを、**アプリの保存先とは別のフォルダー**へ置く。
   - 例: `D:\avs-reference-source\`（`%LOCALAPPDATA%` 配下に置かない）
   - 画像は 3 件以上、ファイル名に**空白・日本語・長音**を含むものを 1 件以上入れる。
3. 実施端末の情報を §4 の表頭へ記録する（Windows 版・ビルド番号・端末種別）。
4. 取り込み先ボリュームの空き容量を控える。

## 3. 実施手順

各手順の「期待」は合否の基準であり、**実施前に結果欄を埋めてはならない**。

### 3.1 OS 標準 picker（P-01〜P-04）

| # | 操作 | 期待 |
|---|---|---|
| P-01 | Project を作成し、`親フォルダーを選択` を押す | Windows 標準の**フォルダー選択**ダイアログが開く。アプリ独自描画の代替 UI ではない |
| P-02 | 取り込みタブで `ラベルなし・画像ファイル` ＋ `参照` を選び、`データを選択して検査` を押す | Windows 標準の**ファイル選択**ダイアログが開き、タイトルが `画像を選択` である |
| P-03 | P-02 のダイアログで **Ctrl + クリック**により 3 件以上を選択して開く | 選択した全件が検査対象になり、件数が検査結果と一致する |
| P-04 | `クラス別フォルダー` ＋ `参照` を選び、ダイアログが開いたら **Esc** で閉じる | `選択をキャンセルしました。` が表示され、検査が開始されない。ジョブが作られない |

### 3.2 Reference アクセスの持続（R-01〜R-04）

| # | 操作 | 期待 |
|---|---|---|
| R-01 | §2 の外部フォルダーを `参照` で取り込み、権利確認のうえ確定する | 結果記録に取り込み件数が表示される。**元フォルダーの中身が増減しない**（コピーされていない） |
| R-02 | アプリを終了し、再度起動して同じ Project を開く | 取り込み済み件数が保持されている |
| R-03 | **OS を再起動**し、アプリを起動して同じ Project を開く | 同上。元データの path が保持され、再取り込みを要求されない |
| R-04 | 元フォルダーを別 path へ移動（rename）し、アプリを起動して同じ Project を開く | 参照できない旨が**明示的に表示**される。破損・空表示・無言の成功にならない |

### 3.3 relink（L-01・L-02）

| # | 操作 | 期待 |
|---|---|---|
| L-01 | R-04 の状態で、`教師データ` タブの「参照元を確認」→「参照元を選び直す」で移動後のファイルを選ぶ | OS 標準のファイル選択が開き、**元と同じ内容のファイルだけ**が受け入れられる。復旧後に再確認すると 0 件になる |
| L-02 | L-01 で**別の画像ファイル**を選ぶ | 「選んだファイルは元の内容と一致しません」と表示され、参照は変更されない |

> **実装状況（2026-09-22 更新）**: relink は `reference:status` / `reference:relink` の 2 channel として公開され、[`src/main/ipc/reference-handlers.ts`](../../src/main/ipc/reference-handlers.ts) が Main 側で OS 標準 picker を開く。Renderer は Project ID と保存済み `imageKey` しか指定できず、path を名指しできない。自動 E2E（[`tests/e2e/import-detection.spec.ts`](../e2e/import-detection.spec.ts)）は picker を置き換えて L-01/L-02 相当を検証済みだが、**OS 標準ダイアログ自体の実機確認は本手順の対象**として残る。
